# Balazhan.kz — сайт детского сада

Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, Lucide. База данных и админ-панель не нужны.

- `/` — казахская версия (основная), `/ru` — русская.
- Компьютер — `src/components/website/`, телефон — `src/components/mobile-website/`, общее — `src/components/shared/`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка production-сборки
```

## Где что менять

| Что | Где |
| --- | --- |
| Адрес, телефон, часы, группы, ссылка на документы | `src/components/shared/config.ts` |
| Все тексты на двух языках | `src/components/shared/i18n.ts` |
| Цвета, формы, анимации | `src/app/globals.css` |

**Документы.** Вставьте ссылку Google Drive в `documentsUrl` в `config.ts` — кнопка заработает, надпись «Скоро будет доступно» исчезнет.

## Фотографии

Кладите файлы в `public/images/` — код менять не нужно, сайт находит их сам при сборке.

| Файл | Куда попадает |
| --- | --- |
| `main-page.png` (или .jpg/.webp) | Главная фотография |
| `main-page2.jpg` или `main-page2.mp4` / `.webm` | Фото или видео в разделе «О нас» |
| `image1.jpg`, `image2.jpg`, … | Галерея, в порядке номеров (png/jpg/webp/avif) |
| `logo.png` | Логотип вместо текстового |

- Пока файла нет, на его месте показана иллюстрация, а не чужое фото.
- Рекомендуемая длинная сторона — до 2000 px. Формат HEIC с iPhone не поддерживается: сохраните его как JPG.
- Рамки на главной и в «О нас» подстраиваются под пропорции файла, поэтому фото не обрезается.
- Текущие фотографии взяты из галереи 2ГИС, список источников: `docs/photo-sources.md`.
- Публикуйте фотографии детей только с согласия родителей.

## Публикация на Vercel

1. Загрузите проект на GitHub и импортируйте его в Vercel: настройки сборки определятся сами.
2. Подключив домен, добавьте переменную `NEXT_PUBLIC_SITE_URL` (например, `https://balazhan.kz`) и пересоберите проект. Без неё в canonical, sitemap и Open Graph будет адрес `*.vercel.app`.
3. Новые фотографии появятся на сайте после следующей публикации.
